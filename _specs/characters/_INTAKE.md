# 캐릭터 자료 넘김 양식

이 파일을 복사해 `_specs/characters/_intake/<영문이름>.md`로 저장하고 채운다.

> **브라우저로 채우는 편이 빠릅니다.** [`tools/intake_form.html`](../../tools/intake_form.html)을
> 더블클릭하면 같은 항목을 빈칸으로 물어보고, 계수 표를 붙여넣는 즉시 항목별로 갈라 보여 준
> 뒤 정리된 자료를 내놓습니다. 이 문서는 텍스트로 주고받을 때 쓰는 같은 내용의 양식입니다.

**변환하지 않는다.** 게임 화면과 위키의 문구·숫자를 **그대로** 붙여넣으면 된다.
퍼센트를 소수로 바꾸거나, 계수를 한 줄로 늘어놓거나, 필요 없는 행을 골라내는 일은
받는 쪽이 한다 — 옮겨 적는 손이 하나 줄수록 조용히 틀릴 자리가 줄어든다.

이 파일이 채워지면 `_specs/characters/<모듈>.txt`(스펙) → `tools/new_character.py`로
이어진다. 전체 절차는 [`docs/character-implementation.md`](../../docs/character-implementation.md).

| 원소 | | 불 / 물 / 얼음 / 번개 / 바람 / 바위 / 풀 |

| 성급 | | 4성 / 5성 |
| 돌파 보너스 스탯 | | 캐릭터 상세 화면에서 **돌파할 때마다 오르는 스탯 하나** (공격력% / 치명타 피해 / 원소 마스터리 / OO 원소 피해 보너스 / 원소 충전 효율 / HP% / 방어력% / 치유 보너스) |

> **돌파 보너스 스탯은 빠뜨리면 계산이 조용히 틀어진다.** 선언이 없으면 보너스가 통째로
> 0으로 잡히고 예외도 경고도 나지 않는다. 이미 등록된 17명 중 4명이 이걸 빠뜨린 상태다.
> 값(예: 38.4%)은 적지 않아도 된다 — **무슨 스탯인지만** 적으면 엔진이 성급·돌파 단계에서
> 계산한다.

**특성 레벨을 올리는 명함** (해당 없으면 비워 둔다)

| | 명함 번호 |
|---|---|

| 원소 스킬 레벨 +3 | |
| 원소 폭발 레벨 +3 | |

## 3. 계수 표

각 특성의 표를 **통째로** 붙여넣는다. 정리하지 말 것.

### 넣는 규칙

- **모든 행을 남긴다.** 지속 시간·쿨타임·소모 스태미나·에너지 회복량처럼 피해와 무관해
  보이는 행도 그대로 둔다. 무엇을 쓸지는 받는 쪽이 고른다 — 골라내다 필요한 행이
  빠지는 쪽이 훨씬 잦다.
- **레벨 범위**: 일반/강/낙하는 **L1~L11**, 원소 스킬·원소 폭발은 **L1~L13**까지.
  (스커크가 있는 물·얼음 파티에서 쓰일 캐릭터라면 스킬·폭발은 L14까지 있으면 좋다.)
- **소수점은 정밀한 쪽.** 위키가 `63.9`와 `63.93`을 둘 다 보여 주면 `63.93`을 쓴다.
  세 자리 표기는 잘린 값이다.
- **한 항목이 상태마다 다른 값을 쓰면 행을 합치지 않는다.** 예를 들어 강공격이 특정
  상태에서 다른 공격으로 바뀌면, 숫자가 같아 보여도 두 행으로 둔다. 어느 상태의 값인지
  이름에 남겨 주면 좋다.
- **한 항목 안의 값은 쪼개지 말고 그대로 둔다.** `23.8%+26.6%`(2타 합)이나
  `공격력의 140%+원소 마스터리의 134.6%`(두 스탯 스케일)는 적힌 그대로가 정보다.
- 표 모양은 아무래도 좋다. 위키에서 긁은 탭 구분, 엑셀 붙여넣기 다 된다. **레벨이 세로인
  표(한 줄이 레벨 하나)를 기본**으로 읽고, 한 칸에 `44.1% / 46.8% / …`처럼 여러 값이
  들어 있어도 헤더 이름과 함께 쪼개진다.

## 5. 채우고 나서

넘겨주시면 받는 쪽이 이렇게 이어 갑니다.

1. `_specs/characters/<모듈>.txt` 스펙으로 옮긴다 (퍼센트 → 소수, 히트 이름, 표 등록)
2. `python tools/new_character.py <스펙> --check` — 계수 길이·단조성·퍼센트 누락·히트 이름
   중복·명함 번호 대조를 기계가 검사한다
3. 뼈대 생성 + 등록 2곳
4. **효과를 어느 훅에 넣을지 표로 정리해 확인을 받는다** ← 여기서 다시 물어봅니다
5. 훅 구현 → `tools/check_characters.py` 점검 → 검증 → 기준선 diff → 웹 반영

**2번에서 거절되면 자료를 다시 여쭙습니다.** 계수가 100배가 되거나 히트가 조용히
사라지는 종류는 여기서 전부 걸리므로, 채우실 때 완벽하지 않아도 됩니다.
